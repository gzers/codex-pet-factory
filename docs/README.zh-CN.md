## 推荐阅读顺序

1. 先看 [项目说明](../README.zh-CN.md)。
2. 从用户图片或描述制作宠物时，看 [Agent 工作流](01-agent-workflow.zh-CN.md)。
3. 修改 CLI、测试或包结构时，看 [开发者说明](02-developer-guide.zh-CN.md)。
4. 安装前使用每个宠物项目生成的 `docs/03-interaction-checklist.zh-CN.md`。
5. 给其他 Codex agent 复用时，看 [Skill](../.agents/skills/codex-pet-factory/SKILL.md)。
6. 需要确认 atlas 布局、每行帧数预算、透明规则、状态设计、QA 标准时，看 [制作参考](../.agents/skills/codex-pet-factory/references/pet-production.zh-CN.md)。
