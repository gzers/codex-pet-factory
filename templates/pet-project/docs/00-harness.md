# Pet Harness

中文文档：[00-harness.zh-CN.md](00-harness.zh-CN.md)

1. H0 Inputs: save source material in `build/input/`.
2. H1 Character: define one unified character sheet.
3. H2 Motion: generate action frames into `build/work/`.
4. H3 Normalize: produce transparent `192 x 208` PNG frames.
5. H4 Package: build outputs for `build/final/`.
6. H5 QA: review `build/qa/` and run validation.
7. H6 Install: publish the final pet from `build/final/`.
